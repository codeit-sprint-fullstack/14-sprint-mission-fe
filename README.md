# 🐼 판다마켓 프로젝트

HTML/CSS를 활용해 구현한 판다마켓 웹 페이지 프로젝트 입니다.

## 🔗 배포 링크
https://fs14-mission2.netlify.app/


## 📌 웹 페이지 소개

판다마켓은 중고거래를 위한 커뮤니티 플랫폼입니다.
상품을 등록하고, 다른 사용자들과 자유롭게 소통할 수 있는 서비스를 제공합니다.

## ✨ 구현 기능

### 공통
- CSS 변수 사용
- Google Analytics 연동

### 랜딩 페이지
- 고정형 네비게이션 바 구현
- 반응형 레이아웃 구현
- SNS 링크 연결
- 페이지 간 이동 기능 구현

### 로그인 / 회원가입 페이지
- `form` 태그를 활용한 로그인/회원가입 폼 구조 구현
- SNS 링크 연결
- 페이지 간 이동 기능 구현

## 🛠️ 기술 스택
- HTML5
- CSS3
